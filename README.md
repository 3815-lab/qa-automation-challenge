# Prueba técnica QA - Automatización E2E y APIs

Repo con los dos ejercicios de la prueba:

| Ejercicio | Carpeta | Herramienta | Opción elegida |
|-----------|---------|-------------|----------------|
| E2E | `e2e-cypress/` | Cypress + TypeScript | Opción 2 - flujo de compra en https://www.saucedemo.com/ |
| APIs | `api-karate/` | Karate + Maven | Opción 1 - signup y login de https://api.demoblaze.com |

Cada carpeta es un proyecto independiente y va a tener su propio `readme.txt` con los pasos de ejecución.

## Requisitos

- Node.js 20 o superior
- Java 17 o superior (Maven no hace falta, se usa el wrapper `mvnw`)
